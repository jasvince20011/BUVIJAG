# BUVIJAG AI

**Sharp Intelligence for a Data-Driven World.**

BUVIJAG AI is an AI-powered business data analysis agent that transforms uploaded business data into understandable insights, visualizations, recommendations, and executive reports.

## Features

- Secure username/password login configured through Streamlit secrets
- Cinematic blue-purple data-world title reveal and themed welcome page
- CSV, Excel, PDF, image, and ZIP ingestion where supported by the app
- Dataset Information: column names, data types, numerical/categorical columns, missing values, and numerical statistics
- Automatic KPI detection and Data Health Score
- Missing-value, duplicate, anomaly, and data-quality detection
- Editable chart types with selection of value, aggregation, sort order, colours, and title
- AI-assisted insights, evidence notes, Executive Summary, and action plan
- Smart Inventory Intelligence and low-stock/reorder alerts
- What-If Business Simulator
- Enhanced multi-page Executive PDF Report with charts and explanations
- Recent-file history during the active app session
- Four themes: Daylight, Dark, Futuristic, and Professional
- Hackathon demo data, presentation, documentation, and demo video

## Run locally

1. Install Python packages:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Create a local secret file at `.streamlit/secrets.toml` (create the `.streamlit` folder if needed) using your own values:

   ```toml
   GEMINI_API_KEY = "YOUR_REAL_GEMINI_API_KEY"
   APP_USERNAME = "your_username"
   APP_PASSWORD = "a_strong_unique_password"
   ```

3. Start the app from the project folder:

   ```bash
   python -m streamlit run app.py
   ```

4. Open the local URL shown in the terminal (usually `http://localhost:8501`).

## Deploy on Streamlit Community Cloud

- Push the extracted project files to a GitHub repository.
- Connect the repository and select `app.py` as the main file.
- In the app's settings, add `GEMINI_API_KEY`, `APP_USERNAME`, and `APP_PASSWORD` in the **Secrets** section.
- Redeploy/restart the app. Never hardcode real credentials in Python.

## Security note — important

**Do not upload `.streamlit/secrets.toml`, `.env`, or any real API keys/passwords to GitHub.** The included `secrets.toml.example` contains placeholders only. If a real key was previously exposed in a screenshot or committed to a repository, revoke it and create a new one.

## Demo dataset

The recommended business analytics demo file is synthetic and includes sales, product, customer, payment, delivery, and inventory information along with controlled quality issues for demonstrating data-health and anomaly features. It is not real customer data.
